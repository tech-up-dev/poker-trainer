Anatomy & layering

The pod is a stack of three layers inside one position:relative wrapper:

Layerz-indexWhat it is
Cards0Two card backs (or face-up cards for hero) sitting behind the identity block, ~4/5 visible above its top edge.
Identity block1The connected pill: position + player-type on the top row, stack on the bottom row. Rounded, overflow:hidden.
Action tag2Orange pill pulled up with a negative margin so it straddles the bottom edge of the identity block.
Dealer button3Optional floating gold chip, top layer so it never gets clipped.

The three identity attributes (position, type, stack) share the cool color family so they read as one unit. Only the action uses orange — it is the one thing that changes turn-to-turn, so it owns the accent color.

Behavior notes for build

FieldRule
Cards presentShow the identity block + card backs only when the player is dealt in. Otherwise render the empty-seat pill.
Action tagShow only when the player has acted this street. Text is dynamic: Check, Call, Fold, 3-Bet $48, All-in, etc. Single orange treatment for all actions.
Player type3-letter code, always uppercase. Reserve ~3 chars of width so codes like NIT/LAG/STP stay centered.
StackCurrency-formatted with a thousands separator ($1,233).
Dealer buttonRendered on exactly one seat per hand.
Carve-out ringThe 2px ring on the action tag and dealer button must match whatever surface sits directly behind them (the canvas color). If a pod ever sits on the felt instead, set the ring to the felt color for that instance.
